# Со стороны пользователя:
•	Новостная лента
•	Каталог с :
o	Пагинацией
o	Фильтрация по каталогу 
o	Поиск 
o	Фильтр в наличии/отсутствуют 
•	Faq c информацией о доставке(делается через декоратор при оформлении), адресе, времени работы, карта яндекса с адресом
•	Корзина( выбираем кол-во, способ доставки(3 вида: самовывоз, доставка по городу(фикс.цена), доставка в другой город(х цена + 50р за единицу товара), адрес, способ оплаты(2: картой при получении, наличными). Чек приходит на почту
•	Аккаунт ( вход по емейл и пароль), регистрация ( пароль, имя, емейл). тут пользователь видит свою скидку( зависит от суммы выкупа максимальная 10 процентов, изначально 0 ), активные заказы
# Со стороны админа: 
Видит заказы, создает посты, добавляет товары 

Товар : категория, количество, название, описание, цена
Заказ: содержимое, статус(создан, собран, доставляется, вручен), стоимость, адрес
